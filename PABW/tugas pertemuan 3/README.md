# 🌋 Website Wisata Gunung Bromo

> 🏞️ Jelajahi pesona alam Bromo—dari lautan pasir hingga hangatnya matahari terbit.

Website informatif untuk memperkenalkan keindahan Gunung Bromo, destinasi wisata di sekitarnya, serta informasi yang membantu pengunjung merencanakan perjalanan.

## 🧭 Tentang Proyek

Proyek pembelajaran web ini dibuat menggunakan **HTML, CSS, dan JavaScript**. Halaman dirancang responsif dengan tema warna yang terinspirasi dari lanskap Bromo: batu vulkanik, pasir, dan cahaya matahari terbit. 🌅

## 🏔️ Isi Website

- 🏠 **Home** — Pengenalan Bromo dengan slideshow lima foto.
- 📖 **Tentang** — Informasi mengenai alam dan budaya kawasan Bromo.
- 🧭 **Destinasi** — Penanjakan, lautan pasir, dan kawah.
- ℹ️ **Informasi** — Fakta dan saran persiapan perjalanan.
- 🗺️ **Peta** — Peta sematan lokasi Gunung Bromo dan tautan untuk membukanya di Google Maps.
- 🎟️ **Paket Wisata** — Pengingat untuk memeriksa tarif dan ketentuan tiket terbaru melalui kanal resmi TNBTS.
- 📸 **Galeri** — Foto yang dapat dibuka dalam tampilan lebih besar.
- 🎬 **Video** — Video wisata dari YouTube.
- 🌐 **Media Sosial** — Tautan pencarian konten Bromo di Instagram, Facebook, dan YouTube; tautan tersebut bukan akun resmi Bromo.

## ✨ Fitur

- 🧭 Navigasi ke bagian halaman dengan penanda bagian yang sedang aktif.
- 🔄 Slideshow Home berganti otomatis setiap 7,5 detik, dilengkapi kontrol jeda/lanjutkan.
- ♿ Slideshow berhenti saat tab browser tidak aktif dan menghormati preferensi reduced motion.
- 🎞️ Animasi elemen saat digulir dan tombol kembali ke atas.
- 🔍 Galeri foto dengan dukungan keyboard dan tampilan lightbox.
- 📱 Layout responsif untuk desktop, tablet, dan ponsel.

## 🛠️ Teknologi

| Teknologi | Peran |
|---|---|
| 🧱 **HTML5** | Struktur dan konten halaman |
| 🎨 **CSS3** | Tema, layout, animasi, dan responsivitas |
| ⚙️ **JavaScript** | Slideshow, navigasi aktif, animasi gulir, dan lightbox |

## 🚀 Menjalankan Website

1. 📂 Buka folder proyek.
2. 🌐 Buka `index.html` di browser.
3. 📶 Pastikan terhubung ke internet untuk melihat peta sematan dan video.

Foto halaman disimpan secara lokal di folder `images/`.
