# 🌋 Website Wisata Gunung Bromo

Website promosi wisata yang dibuat untuk memperkenalkan keindahan Gunung Bromo serta beberapa destinasi dan aktivitas yang dapat dinikmati oleh wisatawan.

---

## 📌 Tentang Project

Website ini merupakan tugas perkuliahan yang dibuat sebagai penerapan dasar **HTML, CSS, dan JavaScript** dalam membangun sebuah antarmuka website.

Konsep website dibuat sederhana dengan mengutamakan informasi wisata, tampilan visual, serta navigasi yang mudah digunakan.

---

## 🏔️ Isi Website

Website Gunung Bromo memiliki beberapa bagian utama:

- **Home** — Tampilan pembuka dan pengenalan wisata Gunung Bromo
- **Tentang** — Informasi singkat mengenai Gunung Bromo
- **Destinasi** — Beberapa lokasi dan kegiatan wisata
- **Paket Wisata** — Informasi pilihan tiket masuk
- **Galeri** — Kumpulan foto Gunung Bromo
- **Video** — Video mengenai wisata Gunung Bromo
- **Tiket Resmi** — Tautan menuju website resmi TNBTS

---

## ✨ Fitur

- Navigasi antar bagian halaman
- Tampilan gambar wisata
- Informasi destinasi dan kegiatan
- Informasi harga tiket
- Galeri foto
- Video wisata melalui YouTube
- Tautan menuju website resmi TNBTS
- Tampilan responsive untuk berbagai ukuran layar

---

## 🛠️ Teknologi yang Digunakan

| Teknologi | Penggunaan |
|---|---|
| **HTML5** | Membuat struktur halaman |
| **CSS3** | Mengatur tampilan dan layout |
| **JavaScript** | Fungsi dasar pada website |
